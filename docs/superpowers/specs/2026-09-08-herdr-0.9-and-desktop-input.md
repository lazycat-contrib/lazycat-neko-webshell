- Verify both normal client/server0.8.2 and0.9.0 paths using actual PTY output callbacks; the old --no-session/direct term.write fixture did not represent production focus-mode tracking.

## Proven desktop regression

Restty's pointer handler sends SGR mouse-down, then focusTypingInput focuses canvas and the hidden IME textarea. With DEC1004 enabled by the real PtyTransport callbacks.onData path, this internal blur emits ESC[O. Herdr0.8.2 releases its input source and clears pending workspace/tab presses, so the later mouse-up cannot activate the target. The plus action runs on mouse-down and still works.

The previous standalone fixture used term.write(), bypassing InputHandler.filterOutput and therefore DEC1004 tracking. It also used monolithic mode. A full WebShell frontend with normal Herdr0.8.2 reproduced down/focus-out/focus-in/up and a failed space click; the focus-boundary fix removes only the false focus-out and the same space/tab clicks succeed. Normal0.9 client-shell does not clear those presses on focus loss, explaining the earlier successful0.9 probe.

Local executable discovery found ~/.local/bin/herdr0.8.2 ahead of /usr/bin/herdr0.9.0. No live binary or session was changed. Runtime-specific test binaries/configs/sockets are isolated.

## Mobile keyboard follow-up

- Resolve a physical key gesture only after a tap releases; scrolling/movement/cancel must not send an early byte or a synthetic duplicate. Keep held-repeat, modifiers, accessibility clicks and synchronous system-keyboard activation usable.
- Preserve saved custom layouts. Add an inert shortcut preview, edit existing custom keys without changing their identity/order, undo the last layout mutation (including delete/reset), and larger reachable editor controls at 375px.
- Restrict reorder gestures to explicit handles, preserve native scrolling elsewhere, and keep arrow controls and focus after edits. Use distinct Command and Keyboard icons for the main category and system keyboard switch.
- Keep all mobile implementation under mobile/. Validate gestures in a real browser and retain deterministic regressions, including literal-backslash edit round trips.
