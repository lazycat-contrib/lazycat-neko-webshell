# 界面材质与动效设计说明

## 目标

在不改变现有信息架构、不删除任何主题、不增加运行时依赖的前提下，让 WebShell 从“主题换色”提升为有明确表面层级、按压反馈和空间关系的终端工作台。

第一轮以 Steel 为默认旗舰风格，同时让 Glass、Porcelain 等现有主题通过共享材质 token 自动获得一致的层级与动效。终端内容、Tab 切换、键盘快捷操作和移动端虚拟键盘保持即时，不增加等待动画。

## 视觉主题与氛围

界面方向是精密、克制、快速的终端工作台。暗色主题主要依赖表面亮度阶梯、边界、内高光和有限的环境阴影建立层级，亮色主题使用更轻的外阴影与清晰的相邻表面差异。主题色只作为低透明度材质染色，不作为大面积装饰。

参考产品的处理原则：

- Warp 通过明确的终端画布与工具层级，让外围控件存在但不抢夺终端注意力。
- Raycast 使用极短反馈和一致的弹层空间来源，让工具显得快速而可靠。
- Linear 依赖细微表面亮度差、边界和克制阴影，而不是堆叠厚重卡片。

## 色彩与材质角色

- `--bg`：终端工作区外围的最低层级画布。
- `--chrome`：顶栏和固定工具栏表面。
- `--surface`、`--surface-2`、`--surface-raised`：内容、交互悬停和浮层的三级表面。
- `--app-wash-*`：应用外壳的低强度环境染色。
- `--topbar-wash-*`：顶栏的局部高光与主题染色。
- `--dialog-wash-*`：设置页、确认框和工具侧栏的材质染色。
- `--shadow-raised`、`--shadow-popover`、`--shadow-deep`：普通悬浮面、菜单和大型弹层的三级高度。

所有主题继续拥有自己的色彩，不新增主题。Steel 补齐默认材质色，其他主题复用已经存在的 wash token。

## 圆角与深度

采用命名圆角阶梯：

- `--radius-xs: 4px`：键帽和紧凑标签。
- `--radius-sm: 6px`：按钮、输入框和菜单项。
- `--radius-md: 8px`：内容块和通知项。
- `--radius-lg: 12px`：菜单、设置弹窗和工具侧栏。
- `--radius-pill: 999px`：圆形按钮、状态点和胶囊控件。

暗色阴影必须包含可感知的投影和顶部内高光，避免黑色阴影在黑底上消失。亮色阴影保持轻量，避免界面像层层浮起的卡片。

## 交互与动效

动效只服务于反馈和空间一致性：

- 普通按钮和图标按钮按下时缩放到 `0.97`，大型列表行缩放到 `0.985`，时长 100 至 140ms。
- 菜单和 popover 使用 150 至 180ms 的 `opacity + translateY + scale(0.98)`，从触发器一侧展开。
- 设置弹窗、快捷键帮助和确认弹窗使用 200 至 220ms 的中心缩放进入。
- 插件工具侧栏使用约 220ms 的右侧进入动效。
- 退出时长短于进入时长。
- 只动画 `transform` 和 `opacity`，display 使用离散过渡进行渐进增强。
- 不给终端内容、Tab 切换、快捷键触发的高频操作增加进出场动画。

统一使用 `cubic-bezier(0.16, 1, 0.3, 1)` 作为快速减速曲线。按压反馈使用更短的 `cubic-bezier(0.23, 1, 0.32, 1)`。

## 组件范围

本轮覆盖：

- 应用外壳与顶栏材质。
- 新建终端、实例切换、Herdr 工作区、通知、设置和 pane 操作菜单。
- 设置弹窗、快捷键帮助、About、通知确认弹窗。
- 插件工具侧栏。
- 普通命令按钮、图标按钮、设置 Tab、菜单项、插件工具 Tab 的按压反馈。
- 移动端普通操作按钮的短按压反馈。

本轮不覆盖：

- 终端内容转场。
- Tab 选择转场。
- 移动端虚拟键盘键位的延迟或弹跳动画。
- 新主题、字体替换、布局重构和插件内部大规模视觉重做。

## 响应式行为

桌面菜单根据顶栏方向调整 transform origin。移动端菜单保持现有定位和尺寸，进入位移缩短，按压反馈控制在 60 至 90ms。设置页、确认框和快捷键帮助继续使用移动端全高安全区布局，动效不改变其几何尺寸。

## 无障碍

`prefers-reduced-motion: reduce` 下移除所有位移和缩放，保留不超过 120ms 的透明度变化。焦点环、键盘访问顺序和 hidden 状态语义保持不变。禁用控件不响应按压缩放。

## 验收标准

- Steel、Glass、Porcelain 三个代表主题的应用外壳、顶栏、菜单和弹窗具备可辨识但克制的表面层级。
- 设置弹窗、右上菜单、通知确认框和插件侧栏出现时没有突兀跳变。
- 常用按钮按下有即时反馈，Tab 与终端交互不被动画拖慢。
- 375px 移动端不出现溢出、遮挡或明显高成本模糊叠加。
- reduced-motion 下没有 transform 动效。
- `npm test`、`npm run typecheck`、`npm run build` 和 `git diff --check` 通过。
