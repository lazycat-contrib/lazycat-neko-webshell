# Herdr 0.7.4 SockAPI and Interaction Adaptation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the sibling Herdr checkout and make WebShell consume Herdr 0.7.4's JSON SockAPI metadata events, terminal titles, and horizontal wheel support.

**Architecture:** The backend will preserve typed workspace and pane presentation snapshots from `session.snapshot`. Focused frontend Herdr modules will apply complete metadata event snapshots, select readable Herdr tab labels, and batch all four SGR wheel directions; `main.ts` will only coordinate the event update and rendering path.

**Tech Stack:** Rust 2024, Axum, Serde JSON, TypeScript 5.9, Vite, Restty, Node test runner, Cargo tests.

## Global Constraints

- Fast-forward `../herdr` to `origin/master` revision `a22454f27ce096585e19d1787dba43f56d1505cf` without creating local Herdr commits.
- Keep Herdr protocol compatibility at `14..=16`.
- Keep Herdr 0.7.3 usable by omitting 0.7.4-only subscriptions when the runtime version is older than 0.7.4.
- Embed Herdr source version `0.7.4`, protocol `16`, schema version `1`, 85 JSON methods, and 26 subscriptions.
- Do not add `pane.graphics.stream` to the JSON allowlist.
- Do not subscribe to `pane.scroll_changed`.
- Do not add a pane attach sidecar or a second PTY observer.
- Do not automatically render arbitrary metadata token values.
- Keep `src/frontend/src/main.ts` limited to event orchestration and rendering calls.
- Preserve the existing first-wheel-event-immediate, remaining-events-per-frame batching policy.
- Release the WebShell as `0.5.33` with tag `v0.5.33` only after all verification passes.

- [ ] **Step 4: Implement the focused state-event module**

Create `src/frontend/src/herdr-state-events.ts`:

```ts
import { herdrPaneInfoFromEvent, herdrWorkspaceInfoFromEvent } from "./herdr-socket-api";
import type { HerdrBridgeState, JsonRecord } from "./types";

export type HerdrResourceEventResult = {
  state: HerdrBridgeState;
  applied: boolean;
};

export function applyHerdrResourceEvent(
  state: HerdrBridgeState,
  event: string,
  data: JsonRecord,
): HerdrResourceEventResult {
  if (event === "workspace.metadata_updated") {
    const workspace = herdrWorkspaceInfoFromEvent(data);
    if (!workspace || !state.workspaces.some((item) => item.workspace_id === workspace.workspace_id)) {
      return { state, applied: false };
    }
    return {
      state: {
        ...state,
        workspaces: state.workspaces.map((item) => item.workspace_id === workspace.workspace_id ? workspace : item),
      },
      applied: true,
    };
  }
  if (event === "pane.updated") {
    const pane = herdrPaneInfoFromEvent(data);
    if (!pane || !state.panes.some((item) => item.pane_id === pane.pane_id)) {
      return { state, applied: false };
    }
    return {
      state: {
        ...state,
        panes: state.panes.map((item) => item.pane_id === pane.pane_id ? pane : item),
      },
      applied: true,
    };
  }
  return { state, applied: false };
}
```
