# Herdr 0.8.0、移动键盘兼容选项与远程回放实施计划

**目标：** 让 WebShell 完整接受 Herdr 0.8.0 SockAPI；提供默认关闭的“自动唤起系统键盘”选项；让远程设备终端在历史缺口较大时先恢复最新尾部而非从最旧历史开始长时间回放。

**边界：** `main.ts` 只做设置和控制器装配；移动行为留在 `mobile/`；Herdr 契约以 `/home/czyt/code/rust/herdr` 的 `dc2506ea8cb58fc8cde7ceb357cad03b1aba0da1` 为来源；远程回放修复位于当前服务端的远程 WebSocket 中继边界，使已部署的兼容 agent 也立即受益，不修改 agent 版本。

## 1. 建立红灯测试

- 在 Rust Herdr 契约测试和前端 SockAPI 测试中要求 protocol 18、0.8.0、当前 revision、`workspace.move_block` 和 `workspace.reordered`；`pane.graphics.stream` 因需要二进制流式 transport，不进入当前 JSON 文本代理 allowlist。
- 在设置迁移测试中要求缺省 `preventMobileKeyboardAutoOpen === false`，并保留显式 `true`。
- 在移动键盘控制器测试中分别验证显式开启后保留自动聚焦、默认关闭时继续抑制 PgUp/PgDn 等快捷键引起的输入法弹出。
- 在远程 WebSocket 中继边界增加测试：回放超过预算时只向浏览器交付最新尾部，并保留远端权威的最新序列。

## 2. 同步 Herdr 0.8.0 SockAPI

- 更新 `src/herdr_socket_contract.json` 的版本、revision、protocol、方法和订阅事件。
- Herdr 0.8.0 才订阅 `workspace.reordered`，使外部批量重排触发权威状态协调，同时避免旧协议因未知事件拒绝整组订阅。
- 让 agent 交互继续支持已具备这些 API 的 protocol 17，并接受当前嵌入契约 protocol 18。

## 3. 增加移动键盘兼容设置

- 在 `Settings`、默认值和迁移中加入 `preventMobileKeyboardAutoOpen`，默认 `false`。
- 在移动设置的触控分组渲染复选开关和中英文说明，并在 shell 元素映射、设置绑定和状态同步中接线。
- 给 `createMobileSystemKeyboardController` 注入动态设置读取和偏好应用入口；开启选项时恢复旧式自动聚焦行为，默认关闭时保留 v0.6.10 的显式键盘模式及其切换、remount、Android Back、overlay/docked 边界。

## 4. 修复远程设备终端回放

- 在远程 WebSocket 中继层识别 replay start/complete，把回放帧按字节和帧数限制为最新尾部后批量交给浏览器，实时帧仍直接转发。
- 转译 replay complete 时保留远端权威 `last_sequence`，而不是退化成浏览器请求时的 `replay_after`。
- 不修改轻量 agent，因此 `AGENT_VERSION`、`MIN_SUPPORTED_AGENT_VERSION` 和 agent protocol 均保持不变，现有兼容远端无需替换即可生效。

## 5. 验证

- 运行新增/相关 Node 与 Rust 测试，确认每个红灯转绿。
- 运行 `npm test`、`npm run build`、`cargo test --workspace --locked` 和 `git diff --check`。
- 检查工作树只包含本任务文件；不提交、不推送、不打 tag，除非用户另行授权。
