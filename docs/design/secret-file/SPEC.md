# 剪贴板机密文件：交互规格（实现规格）

## 目标与默认行为
用户主动点击“机密文件”，将剪贴板文本原样写入当前终端目标实例的临时文件，再选择插入路径或复制路径。默认不发送正文给终端，不自动执行命令，不清空用户剪贴板。附件无法解码，本稿依据现有 WebShell 界面与源码设计。

## 交互
- 桌面：在终端粘贴相关操作旁添加“机密文件”；右键菜单提供同名入口。手机：键盘菜单栏常驻 file-key 图标按钮，位于滚动页签之外、系统键盘开关旁；无可见文字，提供 aria-label 与 title，不依赖悬停或长按。PC 默认 Ctrl+Alt+V（Mac ⌘⌥V），可在面板内改为 K 或关闭；移动端也支持自定义布局引用该动作。
- 点击入口立即捕获 pane id、session id、selector 和会话 generation，并在用户手势内读取剪贴板；随后展示状态面板，无额外创建确认。
- 桌面展示紧凑对话框（约 440px）；手机同一内容为底部面板。标题“机密文件”，持续显示目标实例，并说明以终端登录用户保存。
- 生成中：显示“正在保存…”；禁用重复创建。不显示正文预览、文件名输入、目录选择或权限设置。
- 成功：显示“机密文件已创建”、完整可选择的等宽路径、目标、权限与清理说明。主按钮“插入终端”，次按钮“复制路径”。插入成功关闭面板并返回原终端；复制成功原位反馈“已复制”，面板保持打开。
- 插入只发送路径（按现有终端安全粘贴机制），不附加换行。当前 pane/target/generation 不一致、只读、关闭或连接未就绪时禁用插入；结果保留原目标说明，仍可复制。
- 关闭面板不会删除文件。结果在本页内可重新打开、选择多份文件；显式重新打开同一个 selector/session 时重新绑定当前 pane/generation，打开过程中的目标变更仍拒绝插入；不持久化密钥内容。提供次级“删除此文件”，成功后禁用插入和复制。第一版不承诺固定过期时间：明确“用完请删除；临时目录的系统清理时间不固定”。
- 读取剪贴板为空、权限不足或 3 秒超时：在同一面板直接显示原因与手动输入框；敏感输入默认遮蔽，不自动聚焦以免打开手机键盘，用户主动点击后进入。使用关闭拼写检查、自动修正、自动填充的多行输入。关闭、成功后及时移除引用与 DOM 内容，但不声称浏览器内存已被安全擦除。
- 手动粘贴成功后点击“生成文件”，保持原换行与前后空白。空内容、UTF-8 大于 1 MiB、目标失效就近提示；失败不回显正文，不后台无限重试。
- 清晰说明能力边界：路径能避免直接粘贴正文；AI/agent 若读取文件，内容仍可能进入其上下文。

## 视觉与触控
沿用 styles.css 的字体、色彩、圆角和 motion tokens。只有主动作使用 accent，无大锁头插画，无密钥正文摘要。完整路径允许换行；视觉上不截掉随机文件名。手机按钮至少 48px 高、间距 8px，窄屏纵向排列；底部包含 safe-area inset，面板遵循 visualViewport，高度不足时内容滚动，动作可达。

打开不抢终端输入焦点，不唤起软键盘；对话框开启期间限制焦点范围。Esc/关闭按钮关闭，恢复入口焦点；插入成功后恢复终端焦点。支持屏幕阅读器状态播报、可见焦点、系统减少动态效果。面板进入 210–220ms、退出 150–160ms，仅 opacity/transform；按下 120ms、scale(.97)。快捷键触发立即显示，键盘导航无装饰性动画，不增加动画库。

## 技术边界与项目结构
- Rust 2024 provider；TypeScript + Vite 前端，无 React。
- 前端所有特有状态、视图、控制器置于 `src/frontend/src/plugins/file-transfer/secret-file-*.ts`。
- 移动端入口及专有样式放 `src/frontend/src/mobile/`；`main.ts` 只接线。复用现有 i18n、主题、dialog/focus 与终端粘贴接口。
- 后端使用现有鉴权后的 file-transfer Connect 调用入口，新增明确的 `secret_create` / `secret_delete` 操作。实现脚本构建与安全策略放聚焦模块，不复用普通上传的覆盖写入脚本。
- 以目标登录用户身份、非 PTY stdin 传入正文；禁止放在命令参数、shell 插值、日志、错误详情、URL 或浏览器持久化存储中。限制请求大小、进程运行时长与输出。
- 目标 `/tmp` 下原子创建随机私有目录（0700）及随机文件（0600），路径格式为 `/tmp/lazycat-webshell-secret-<32位随机十六进制>/key-<32位随机十六进制>`。不接受客户端指定创建路径，失败清理未完成文件，不跟随攻击者符号链接。
- 删除只允许此功能创建且归当前授权目标/用户所有的文件，不能把任意 path 直接传给 rm。删除成功才更新 UI；关闭 UI 不等于删除。
- 优先 provider-only 实现，不改 Herdr allowlist 或轻量 agent 协议。若最终必须改变 agent 行为，再按 AGENTS.md 独立版本规则处理，不能为应用版本随意升级 agent。

代码风格：依赖注入与强类型，与现有 controller 一致。例如：
```ts
type SecretFileResult = { path: string; target: SessionTarget };
// 定义只携带路径的结果，正文不进入 view state 或结果存储。
```

## 验收与验证命令
- Rust 测试覆盖原样保留多行/空白、0600/0700、并发随机性、符号链接边界、失败清理、权限/目标约束、空/超限输入与删除边界。
- 前端 `.test.mjs` 覆盖权限降级、去重、捕获目标后切换会话、复制失败保留路径、插入无回车、关闭后晚到响应和删除后状态。
- 浏览器验证 1280px、390px、320px，长路径、键盘操作、焦点恢复、减少动态效果。真实移动设备另验 Safari 剪贴板手势、中文输入和软键盘/安全区。
```sh
cargo test secret_file
npm run test:frontend
npm run typecheck
npm run build
```
- 始终遵守 AGENTS.md；不新增依赖、不改鉴权、不部署、不提交密钥。不把原型状态演示当作后端验证结果。
