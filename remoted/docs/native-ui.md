# 原生客户端界面与验收

原生客户端的首要任务是进入获授权会话并实际操作。连接和资源检查不是首页内容。

## 导航

- 桌面宽度至少 760 点时，左侧 280 点为设备与会话栏，右侧为工作区；默认窗口 1100 × 760。
- 手机和较窄窗口使用左侧抽屉；主界面展示会话列表，进入会话后保留返回入口。
- Herdr 与普通终端是两个独立分类。Herdr 按授权工作区和窗格导航；普通终端按授权已有会话导航。
- 设备选择切换实际连接，不只更改标签。不同主机的资源、控制权、文件和请求不能串用。
- 配对、Relay 地址、忘记设备等留在连接设置中。公共 Relay 按钮只填入草稿，不触发配对。
- 从会话返回列表、查看文件或打开设置不应丢掉终端输出、VT 状态或输入草稿。

## 会话操作

保留完整终端交互，同时提供普通原生文本输入框，以支持中文 IME 和触屏键盘。
输入发送到真实会话，不把终端输出伪装成结构化聊天消息。Herdr Agent 的结构化聊天能力若无相应
接口支持，不得用本地气泡或演示文本宣称已实现。

操作授权和当前控制权分别判断。只读设备不能取得控制权、输入或上传；可操作设备需要取得
控制权，释放后立即恢复只读输出。输入、Esc 和 Ctrl+C 都使用真实终端协议。

启动恢复上次选中的已配对主机；临时网络失败使用有上限的退避重连。手动断开停止自动重连，
认证或撤销错误需要用户处理。重连不重放尚未确认的命令和文件操作。

## 视觉与动效

使用 NSH 现有语义主题，浅色和深色均须检查。普通文字、辅助文字和选中态需保持可读对比度。
使用系统字体，终端使用等宽字体；间距采用 4 点阶梯，触屏目标至少 48 点，焦点环保持可见。
会话导航用列表行，避免把每个会话做成大块表单按钮。

高频切换会话、键盘输入、终端输出不加进场动画。抽屉沿左边缘进出，使用 NSH Sheet 的原生
平移和透明度动效及其减少动态效果分支；不引入额外 Web 动画依赖，不等待动画后才开始连接。

参考用户提供的 Alma 手机/桌面截图及本地 Cindy 的 sidebar shell、MachineSwitcherMenu、
会话导航和 composer 交互。实现使用 NSH，而不是复制 Electron/React 组件。

## 发布验收

- 在真实公共 Relay 上验证加密业务链路，而不只测试健康检查。
- 验证 Herdr 窗格归属、打开、控制、输入和输出；拒绝不属于授权会话的窗格。
- 验证手机抽屉、桌面常驻侧栏、两类导航、设备切换、输入草稿、返回、只读和文件操作。
- 在浅色、深色、小屏、桌面、键盘弹起及减少动态效果下检查实际画面与布局。
- 记录实际跑过的环境与限制；模拟适配器不能等同于用户真机或真实 LightOS 目标。

## 产品名称和互操作边界

客户端名称为 **neoko-terminal**。Rust + NSH 直接构建 Windows、macOS、Linux 和 Android 的原生
界面，不使用 WebView 或 Electron。WebShell 保留为浏览器入口，两端复用同一主机上的现有普通
终端会话、Herdr 工作区和授权文件目录；不能为了展示原生终端而悄悄创建另一份 shell。

安装标识、凭据键、Android applicationId 和既有配对保留，以支持现有客户端原位升级。
远程控制权限以主机为准，终端控制权在共享会话中仲裁。不同前端同时访问时，输出可观察，
写入必须持有控制权；不以产品改名或 UI 分类绕过已有授权。
